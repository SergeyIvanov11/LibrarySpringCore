Управление библиотекой

Доменная модель Book — id, title, author, available (boolean)
Reader — id, name, type (enum: REGULAR, VIP)
Loan — book, reader, loanDate

Управление сущностями должно происходить через сервисы и репозитории, они должны быть синглтон-бинами
 Loan должен быть бином-прототипом  NotificationService пишет в консоль с помощью логгера о любом изменении с доменными сущностями, он должен быть ленивым бином
Приложение должно запускаться в 2 режимах работы: dev и prod. В dev установлен DEBUG уровень логгирования, в PROD - INFO. 
Использовать SLF4J и logback. Сделать кастомный паттерн лог-сообщений: YYYY-MM-dd HH:mm:ss [LogClass] - Message
При старте приложения писать в консоль с каким профилем приложение запустилось При создании бина Loan писать в консоль сообщение 3-мя способами:
- через postConstruct
- через BPP
- через InitMethod
